Proyectos

LaVitrina

LaVitrina es una web para organizar tus colecciones y conectar con personas que comparten tus mismos gustos.

LaVitrina es una plataforma social para coleccionistas que permite organizar colecciones, controlar el progreso, gestionar duplicados y realizar búsquedas avanzadas.

Incorpora perfiles públicos, sistema de amistades, mensajería en tiempo real y herramientas para descubrir y contactar con otros coleccionistas. También cuenta con un panel de administración propio para gestionar colecciones, usuarios, imágenes y estadísticas.

Desarrollada con JavaScript, HTML y CSS, utiliza autenticación, PostgreSQL, almacenamiento y comunicación en tiempo real. La infraestructura está autoalojada en una Raspberry Pi mediante Docker, utilizando Supabase Self-Hosted.
